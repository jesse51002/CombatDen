# Cutout golden-corpus image provenance

Every image here is either generated by us or public domain. No
copyright-encumbered assets.

## Our own work

- `celebration_image.cutout.png` — produced by this pipeline (smoketest
  run). The composed-subject regression case (the AFTER).
- `pipeline_cycling_saddle.before.png` / `pipeline_cycling_saddle.cutout.png`
  — a real smoketest pipeline run (run id `20260518T000531Z`): the raw
  generated image and the background remover's result, committed as-is.
  The corpus's first fully real (non-synthesized) BEFORE/AFTER pair. Same
  license as this repo.
- `celebration_image.before.png` — the paired BEFORE: the same subject
  composited on the flat solid backdrop the generator produced. A
  deterministically built fixture, committed as-is; the shared BEFORE
  for the whole base-derived family.
- `web_pd_clean_icon.before.png` — the paired BEFORE for the clean icon:
  the public-domain icon composited on the flat solid backdrop. Built
  the same way; same public-domain status as its source icon.
- `synthetic_*.png` — deterministically derived from
  `celebration_image.cutout.png` (opaque canvas re-added / subject
  erased) and committed as-is. Same license as this repo.

## Public domain (Wikimedia Commons)

- `web_pd_clean_icon.png` — from
  [File:Sample_User_Icon.png](https://commons.wikimedia.org/wiki/File:Sample_User_Icon.png).
  Public domain: simple geometry, ineligible for copyright. Re-saved as
  RGBA PNG, otherwise unmodified.
- `web_pd_photo_unremoved.png` — from
  [File:NASA-Apollo8-Dec24-Earthrise.jpg](https://commons.wikimedia.org/wiki/File:NASA-Apollo8-Dec24-Earthrise.jpg).
  Public domain (PD-NASA, solely created by NASA). Converted to PNG and
  downscaled to 768 px; not otherwise altered.

Note: genuine "bad background removal" examples are not sourceable
license-clean at scale, so the `failed_removal` / `damaged` classes are
synthesized — they are *exact* transforms (opaque canvas re-added; subject
erased), which exercises the validator's two failure clauses precisely.
